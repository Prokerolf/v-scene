# Project rules — read this first, every time

## What we are building
A web app that helps medical students learn Clinical Reasoning and History Taking through interactive case simulations using Gemini AI.

The person you are working with is a **doctor, not a programmer**. They are the product owner. You are the engineer.

## How to work with me
- I describe WHAT I want and HOW I'll know it's done. You decide HOW to build it.
- ALWAYS show me a short plan and task list BEFORE you start building. Wait for me to approve it. Do not start coding until I say "go" or "proceed".
- Keep the plan in plain English/Thai. No deep technical jargon.
- Work in SMALL steps. Build one feature, show me it working in the browser, then move to the next.
- After you build something, OPEN IT IN THE BROWSER, click through it, and show me a screenshot or recording so I can see it actually works.
- If something is ambiguous, ASK me one clear question instead of guessing.
- If you hit an error, explain in one plain sentence what went wrong and what you're trying next.

## Technical defaults
- Build a simple web app that runs in a browser. Prefer the simplest, most popular, well-documented tools (React, Vite, Tailwind, Firebase).
- Make it work on a phone screen as well as a laptop.
- Keep the code organized and commented.

## MEDICAL SAFETY RULES — these are non-negotiable
- This is a LEARNING tool, not a clinical tool. It must NEVER be used to make a real diagnosis or treatment decision about a real patient.
- Put a visible disclaimer on the app: "For education only. Not medical advice."
- NEVER hardcode or store real patient data. All examples must be fictional.
- When the app states a medical fact, dose, or guideline, keep a note of where it should come from so I can fact-check it. Do not invent specific numbers. If unsure, flag it for me to verify.

## Definition of done (acceptance criteria)
A task is only "done" when:
1. It works when clicked through in the browser
2. It still works on a phone-sized screen
3. Nothing that worked before is now broken
